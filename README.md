# ML_Project_no1

## Code guide

`main.ipynb` loads training and test CSV files, normalizes features, holds out validation data, trains a perceptron, and explores polynomial features before producing predictions. `train.csv` and `test.csv` are the notebook inputs; `preds.csv` is a saved output. Open the notebook from the repository root and run cells in order after installing pandas, NumPy, Matplotlib, and scikit-learn. Saved predictions and notebook outputs are historical; they were not regenerated for this README.
